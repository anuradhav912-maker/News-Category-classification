# News Category Classification using NLP and Machine Learning

## Project Overview

This project classifies news articles into different categories using
Natural Language Processing and Machine Learning techniques.

## Objective

- Clean and preprocess news text
- Convert text into numerical features using TF-IDF
- Train multiple machine learning algorithms
- Compare their performance
- Select the best-performing model
- Predict categories of new news articles

## Dataset

AG News dataset was used for this project.

The dataset contains four news categories:

- World
- Sports
- Business
- Sci/Tech

## Technologies Used

- Python
- Pandas
- NumPy
- NLTK
- Scikit-learn
- Matplotlib
- Seaborn
- TF-IDF
- Google Colab
- GitHub

## Machine Learning Algorithms

1. Logistic Regression
2. Multinomial Naive Bayes
3. Linear SVM
4. Random Forest

## NLP Techniques

- Text cleaning
- Stopword removal
- Lemmatization
- TF-IDF Vectorization

## Model Evaluation

The models were evaluated using:

- Accuracy
- Precision
- Recall
- F1-score
- Confusion Matrix

## Result

The machine learning algorithms were compared and the best-performing
model was selected based on its classification performance.
